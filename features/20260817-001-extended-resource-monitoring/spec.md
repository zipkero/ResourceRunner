# Network·Disk 확장 리소스 모니터링 명세

## 2026-10-03 실제 화면 피드백 — 이전 샘플 치수보다 우선

사용자는 CPU·Memory가 그대로인 채 스크롤되는 중간 화면과 Network·Disk의 지나치게 작은 글씨를 반려했습니다. 네 카드 전체를 동시에 줄여 **현재 지원 화면에서 스크롤 없이 모두 표시하고 가독성을 확보하는 것**이 우선입니다. 이전 샘플의 590pt 높이와 6.67/7pt 글꼴은 강제하지 않습니다. 요약의 제목·보조 정보·단위·TOP 5는 10pt 이상을 기본으로 하고 대표 숫자는 약 17.33pt, CPU 그래프는 약 66.67pt를 유지합니다. 본체 폭280pt·padding8pt·카드 간격6pt는 유지하되 높이는 실제 전체 렌더와 가용 화면으로 확정합니다. 본체에는 ScrollView를 두지 않습니다. 정보 삭제·말줄임으로 맞추지 않으며 TOP 5 아래 3pt, Network·Disk 하단 안내 삭제와 Disk 옆 그래프 요구는 유지합니다. 실제 아이콘·Memory 정보·전체 값과 상세의 기존 글꼴/스크롤을 보존합니다. 전체 배치가 끝나기 전 중간 앱을 사용자 화면에 띄우지 않습니다. Network의 활성 종류가 많아 이름 나열이 길어질 때 요약 카드에는 종류 수와 활성·미확인 개수를 표시할 수 있으며, 전체 종류 이름은 상세와 AX에 그대로 제공합니다. 소수 종류의 이름 표시는 유지합니다.


## 1. 범위

이 feature는 M3의 Network·Disk 수집, 기본 카드와 카드 옆 상세 팝업을 구현하고,
CPU·Memory와 함께 네 리소스를 하나의 대시보드에서 확인할 수 있게 합니다.
현재 송수신·읽기·쓰기 속도, 인터페이스·장치·볼륨 정보,
저장 공간, 수집 실패 격리와 네 카드의 화면 내 접근을 포함합니다.

누적 카운터로 속도를 계산할 때 첫 샘플, 수집 중지·시스템 슬립 복귀,
인터페이스·장치 변경과 카운터 초기화를 새 기준점으로 처리합니다.
저장 공간과 인터페이스 주소·상태는 실시간 속도보다 낮은 빈도로 갱신합니다.

M2가 완성한 CPU·Memory 수집과 카드 동작을 유지하면서 공통 일정·생명주기·이력·표시 구조를 확장합니다.
카드 넷을 지원 화면에서 모두 사용할 수 있도록 본체 배치 구조를 변경하는 일도 이 feature의 범위입니다.
2026-10-03 사용자가 승인한 280×590pt 축소 샘플을 기준으로 네 카드를 스크롤 없이 한눈에 표시합니다.
타이틀·CPU 그래프·Network 속도 수치는 기존의 약 2/3 크기로 줄이고 Memory 구성 바와 두 카드의 TOP 5를 유지합니다.
Disk는 작은 읽기·쓰기 수치 옆에 미니 그래프를 배치합니다. Network는 그래프 없이 표시합니다.
Network·Disk 하단의 현재 측정·보조 정보·용량 확인 경과 안내 문구는 제거하고 상세와 접근성에서 상태·갱신 정보를 유지합니다.
TOP 5 제목 아래에는 첫 앱 행과 구분되는 작은 여백을 둡니다. 실제 화면 가용 영역과 팝오버 chrome을 고려하며 정보를 자르지 않습니다.
캐릭터 자산·메뉴바 애니메이션은 기존 결정대로 별도 후속 범위입니다.

### 1.2 유지하는 확정 판단

2026-08-17 승인된 SPEC의 다음 결정을 유지합니다.

- Network 대표 속도는 loopback을 제외한 물리 인터페이스의 합계이며,
  VPN 터널 인터페이스는 상세에서만 제공합니다.
  물리 경로와 터널을 함께 더해 같은 트래픽을 이중 계산하지 않습니다.
  기본 경로 인터페이스 하나만 대표로 삼거나 loopback 외 전체를 단순 합산하지 않습니다.
- 프로세스별 Disk I/O와 앱 단위 Disk 순위는 이 feature에서 제공하지 않습니다.
- 유지되는 CPU·Memory 그래프는 최근 10분으로 고정합니다. 1분·5분·10분 선택과 사용자 갱신 속도 설정은 M4 소관입니다.
  Network 요약 그래프는 표시하지 않고 Disk는 읽기·쓰기 옆 미니 그래프를 제공합니다. 상세에 새 그래프를 추가하지 않습니다.
- 이 단계의 시스템 도구 비교는 기존 완료 조건 §5.6의 변화 방향 검증입니다.
  출시를 위한 수치 허용 오차·반복 측정·성능·장기 안정성 최종 관문은 M5에서 다룹니다.

`docs/product.md`·`docs/design.md`의 미확정 목록에 남은 VPN 합산과 프로세스별 Disk I/O 문구는
위의 승인된 feature 결정을 다시 미확정으로 만들지 않습니다.
수집 API, 장치 식별·집계 방법, 속도 그래프의 세로 범위와 구체적인 비교 절차는 DESIGN의 조사·결정 대상입니다.
제품 요구사항이나 완료 기준을 바꿔야 하면 SPEC 개정 대상으로 반환합니다.

## 2. 목표

- 사용자가 한 팝오버에서 CPU·Memory·Network·Disk의 현재 상태와 CPU·Memory·Disk의 최근 흐름을 읽고,
  네트워크 전송과 디스크 입출력 중 어느 자원이 바쁜지 구분할 수 있게 합니다.
- 연결·장치 변경과 수집 중지 이후의 카운터 차분이 음수·허위 급증이나 잘못된 이력으로 이어지지 않게 합니다.
- 네 카드의 상태 표현·단위·선택과 복귀를 일관되게 제공하고,
  작은 화면에서도 모든 카드와 상세에 마우스·키보드로 도달할 수 있게 합니다.
- 한 Collector의 실패와 느린 보조 정보 조회가 다른 카드의 수집·표시와 메뉴바를 막지 않게 합니다.

## 3. 제약

- macOS 26.5 이상 Apple silicon에서 App Sandbox를 유지하며 앱 실행 파일은 arm64만 포함합니다.
  별도 Helper, 관리자 권한, 시스템 확장, 추가 상주 실행 파일과 사용자 승인 프롬프트를 요구하지 않습니다.
- 수집 데이터는 외부로 전송하지 않고 앱 메모리에만 유지하며 재시작 후 복원하지 않습니다.
- 제공되는 CPU·Memory·Disk 최근 그래프는 10분 창과 실제 샘플 시각을 사용합니다.
  미수집·기준점 전용·실패 구간을 0이나 가상 과거 값으로 채우지 않고, 중지 전후를 선으로 잇지 않습니다.
- 속도는 설정된 타이머 간격이 아닌 실제 경과 시간으로 계산합니다.
  첫 샘플, 중지·시스템 슬립 복귀, 허용 범위를 넘는 지연과 카운터 기준 변경에서 이전 기준점을 이어 쓰지 않습니다.
  정상적인 팝오버·전력에 따른 주기 변경 자체를 수집 중지로 취급하지 않습니다.
- 일반 모드의 Network RX·TX와 전체 Disk I/O는 팝오버 열림 1초·닫힘 2초를 기준으로 합니다.
  저장 공간은 열림 30초·닫힘 60초, 인터페이스 주소·상태는 변경 감지 또는 열림 30초·닫힘 60초로 갱신합니다.
  저전력에서는 기존 일정 제어의 감속 원칙을 적용하고,
  화면 잠금·디스플레이 슬립·빠른 사용자 전환으로 화면을 볼 수 없으면 수집을 중지합니다.
  구체적인 일정 배선과 지연 허용 범위는 DESIGN에서 확정합니다.
- 저장 공간·주소·상태의 갱신과 실시간 속도 수집은 책임을 분리합니다.
  느린 보조 조회가 속도 수집을 지연시키거나 다른 카드의 갱신을 막지 않습니다.
- 연결 없음, 지원되지 않는 지표, 조회 실패와 수집 중지를 구분합니다.
  읽지 못한 값을 추정하거나 0으로 표시하지 않습니다.
- 카드 상세는 그 카드 옆 팝업으로 열립니다. 본체는 상세를 위한 자리를 예약하지 않으며,
  상세 개폐·값 변화·수집 상태 전이로 카드 크기와 위치가 흔들리지 않습니다.
- 본체 배치는 지원 화면의 가용 영역 안에서 네 카드와 상세에 도달할 수 있어야 합니다.
  승인된 축소 샘플을 기준으로 네 카드의 요약 정보를 스크롤 없이 함께 표시합니다.
  CPU 그래프를 약 2/3로 줄이고 Memory 구성 바·TOP 5 정보를 유지하며 Disk 미니 그래프를 수치 옆에 배치합니다.
  Network·Disk 하단의 측정·보조 정보 경과 안내 문구는 표시하지 않습니다.
  실제 가용 높이가 축소 본문보다도 작은 예외 화면에서의 도달 수단은 DESIGN에서 정보 손실 없이 결정합니다.
  배치 구조는 DESIGN에서 결정하고 기존 CPU·Memory의 정보·동작·접근성을 유지합니다.
- 제공되는 CPU·Memory·Disk 그래프와 각 카드 보조 정보의 값이 없어도 같은 높이의 자리표시를 사용합니다.
  자리표시로 측정값을 지어내지 않습니다.
- 모든 그래프는 최신 공통 판 규칙을 따릅니다. 시간 창 전체의 무채색 판 면으로 범위를 나타내고,
  윤곽선·세로 눈금 없이 가로 기준선 하나를 데이터보다 약하게 둡니다.
  값 있음·없음의 판 크기와 위치가 같고, 미수집 구간에는 점·선·별도 구획을 만들지 않습니다.
- 정상·경고·위험 등의 상태를 색상만으로 나누지 않으며 카드의 현재 상태와 주요 수치에 접근성 이름을 제공합니다.
  상세 진입·복귀와 네 카드 접근은 키보드로 수행할 수 있어야 합니다.
- 앱 자체의 수집 활동이 Network·Disk 측정 결과를 의미 있게 왜곡하지 않아야 합니다.

## 4. 제외 범위

- 프로세스별 네트워크 사용량, 원격 호스트, 포트별 통계, 패킷 캡처와 Network Extension.
- 프로세스별 Disk I/O와 앱 단위 Disk 순위.
- 캐릭터 자산과 메뉴바 애니메이션, Disk 발밑 효과와 Network 이동 효과.
- 그래프 시간 범위 선택, 사용자 갱신 속도·카드 표시 설정과 영구 저장, 기본값 복원, 로그인 시 자동 실행.
- 네트워크 속도 임계치에 따른 경고나 알림, 별도 상세 창 고정.
- VoiceOver 실제 낭독 확인, 출시를 위한 수치 정확성·성능·장기 안정성 최종 관문.
- 코드 서명·공증, 업데이트 전달과 설치 가능한 배포물.

## 5. 완료 조건

1. 팝오버를 열면 Network 카드에 현재 다운로드 속도, 현재 업로드 속도,
   현재 활성 인터페이스와 Wi-Fi·Ethernet·VPN 구분이 표시됩니다.
   요약 카드에는 그래프를 표시하지 않습니다.
2. 팝오버를 열면 Disk 카드에 현재 읽기 속도, 현재 쓰기 속도,
   시스템 볼륨 전체 용량과 사용 가능한 공간이 표시됩니다.
   작은 읽기·쓰기 수치 옆에 최근 10분의 두 계열 미니 그래프를 표시합니다.
3. Network 카드를 선택하면 그 카드 옆 팝업에 인터페이스별 RX·TX, IPv4·IPv6 주소,
   누적 송수신량, 인터페이스 상태와 복수 인터페이스 사용 상태가 표시됩니다.
   다시 선택하거나 명시적인 복귀 동작을 수행하면 팝업이 닫히며 요약 상태로 돌아옵니다.
4. Disk 카드를 선택하면 그 카드 옆 팝업에 볼륨별 전체·사용 중·사용 가능한 공간,
   장치별 읽기·쓰기 속도, 누적 읽기·쓰기 크기와 외장 디스크 상태가 표시됩니다.
   다시 선택하거나 명시적인 복귀 동작을 수행하면 팝업이 닫히며 요약 상태로 돌아옵니다.
5. Network 대표 속도가 물리 인터페이스 합계이고 VPN 터널 인터페이스는 대표값에 더해지지 않습니다.
   VPN 연결·해제에서 같은 트래픽이 이중 계산되지 않으며 터널 인터페이스는 상세에서 확인됩니다.
6. 대용량 다운로드·업로드에서 Network 값이, 대형 파일 읽기·쓰기에서 Disk I/O 값이 기대한 방향으로 변하고,
   정해진 비교 절차에서 macOS 시스템 도구와 변화 방향이 일치합니다.
   비교 대상·관측 구간·단위·집계 범위와 원시 근거를 남기고, 서로 다른 측정 정의를 같은 값으로 비교하지 않습니다.
7. Wi-Fi와 Ethernet 전환, VPN 연결·해제, 네트워크 연결 없음, 외장 디스크 연결·해제에서
   음수나 비정상적인 급증 같은 순간값이 나타나지 않고 앱이 종료되지 않습니다.
   연결 없음과 인터페이스·외장 디스크 상태가 조회 실패와 구분되어 표시됩니다.
8. 시스템 슬립에서 복귀한 첫 샘플은 수면 시간을 경과 시간으로 삼은 속도를 만들지 않고 기준점만 갱신합니다.
   화면 잠금·디스플레이 슬립·빠른 사용자 전환에 따른 수집 중지에서도 재개 첫 샘플이 기준점만 갱신하고,
   유지되는 CPU·Memory·Disk 그래프의 중지 구간은 비어 있으며 전후 점이 선으로 이어지지 않습니다.
9. 인터페이스·장치 집합이나 누적 카운터의 기준이 바뀌면 첫 샘플을 새 기준점으로 처리해 이전 값과 이어 붙이지 않습니다.
   연결 해제된 대상의 값이 현재값에 남거나 다른 대상의 이력으로 이어지지 않습니다.
10. 저장 공간이 실시간 I/O보다 느린 주기로 갱신되고, 두 갱신 주기의 차이가
    상세·접근성에서 확인 가능하고 요약 하단의 갱신 경과 안내 문구는 표시하지 않습니다. 느린 보조 조회가 실시간 속도 갱신을 막지 않습니다.
11. Network 또는 Disk 수집이 실패해도 그 카드만 실패 상태가 되고 나머지 세 카드와 메뉴바 앱은 계속 동작합니다.
    CPU·Memory의 실패도 Network·Disk 수집을 막지 않으며, 실패한 측정값이 0으로 바뀌지 않습니다.
12. 네 카드가 요약 구조, 선택·복귀, 수집 중·정상·실패·중지 상태 표현과 단위 표기 원칙을 공유합니다.
    서로 다른 지표의 의미를 같은 단위로 오인시키지 않고 현재값과 누적량·저장 공간을 구분합니다.
13. 선택한 배포·Sandbox 조건에서 필수 Network·Disk 지표의 접근 가능 범위가 실제로 검증됩니다.
    얻을 수 없는 항목은 근거와 함께 기록하고, 필수 항목의 미확보를 구현 완료로 처리하지 않습니다.
14. Network·Disk 카드의 현재 상태와 주요 수치에 접근성 이름이 제공되고 키보드로 탐색할 수 있으며,
    색상 없이도 상태를 구분할 수 있습니다. 상세 팝업의 정보도 접근성 계층에서 도달할 수 있습니다.
15. 팝오버를 연 직후 값이 없는 상태에서 첫 수집이 도착하거나 수집 중·정상·실패·중지 사이를 오가도
    카드 크기와 위치가 변하지 않습니다. CPU·Memory·Disk의 값이 없는 그래프와 각 카드 보조 정보 자리는 같은 높이의 자리표시로 채우며,
    상세 팝업을 열고 닫아도 카드가 움직이지 않습니다.
16. 지원 화면의 가용 영역 안에서 네 카드와 각 상세 정보에 마우스·키보드로 모두 도달할 수 있고,
    마지막 카드가 화면 밖에 잘려 사용할 수 없는 상태가 생기지 않습니다.
    승인된 축소 샘플의 네 요약 카드는 스크롤 없이 함께 보이며 실제 화면·chrome을 포함해 확인합니다.
    타이틀·CPU 그래프·Network 숫자는 약 2/3 크기이며 Disk 수치와 옆 미니 그래프는 작게 배치합니다.
    CPU·Memory TOP 5 제목과 첫 앱 행 사이에 작은 여백을 두고 정보·선택·복귀·접근성을 유지합니다.
17. [철회] Network·Disk의 정상·자리표시 그래프와 공통 판 면 요구는
    2026-10-03 사용자의 Network·Disk 요약 그래프 제거 지시로 철회합니다.
    CPU·Memory의 기존 공통 그래프 판 규칙은 해당 선행 feature 계약대로 유지합니다.
18. Network 연결 속도와 Disk IOPS는 선택한 API·Sandbox 조건에서 얻을 수 있으면 상세에 제공하고,
    얻을 수 없으면 지원 여부·사유를 기록해 측정값으로 추정하지 않습니다.
    조건부 항목의 미지원이 필수 송수신·읽기·쓰기 속도와 저장 공간 표시를 막지 않습니다.
19. Disk 미니 그래프는 최근 10분의 읽기·쓰기 두 계열과 공통 판 면·기준선을 유지하고, 미수집 구간을 이어 붙이지 않습니다.
    작은 수치와 그래프가 나란히 놓여도 단위·상태·부분값의 의미를 유지하며 Network에는 그래프를 표시하지 않습니다.
