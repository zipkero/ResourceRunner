# ResourceRunner

> 움직임은 현재 상태를 보여주고, 대시보드는 그 원인을 설명합니다.

ResourceRunner는 움직이는 메뉴바 캐릭터와 한눈에 읽히는 대시보드로 macOS의 CPU, 메모리, 네트워크와 디스크 상태를 설명하는 네이티브 리소스 모니터입니다.

## 왜 ResourceRunner인가요?

가벼운 메뉴바 모니터는 현재 수치만 보여주는 경우가 많고, 상세한 시스템 분석 도구는 필요할 때마다 별도 창을 열어야 합니다.

ResourceRunner는 macOS 사용자와 개발자가 메뉴바에서 부하를 빠르게 알아차리고, 한 번의 클릭으로 최근 변화와 원인 프로세스를 확인할 수 있게 합니다.

~~~text
움직이는 메뉴바 캐릭터
        ↓ 클릭
CPU · Memory · Network · Disk 대시보드
        ↓ 카드 선택
상세 지표 · 최근 그래프 · 원인 프로세스
~~~

## 주요 기능

- CPU 부하와 Memory Pressure를 반영하는 메뉴바 캐릭터
- CPU·Memory·Network·Disk 카드와 최근 1분·5분·10분 그래프
- CPU·Memory 사용량 TOP 5와 앱 단위 프로세스 집계
- 카드별 상세 지표와 독립적인 수집 실패 상태
- 갱신 속도, 그래프 범위와 애니메이션 설정
- 팝오버, 저전력 모드와 화면 잠금 상태에 따른 자동 수집 감속
- 로그인 시 자동 실행
- 동작 줄이기, 키보드 탐색과 VoiceOver 대응

ResourceRunner는 별도 Helper와 관리자 권한을 요구하지 않고, 수집 데이터를 외부로 전송하거나 장기 이력으로 저장하지 않습니다.
