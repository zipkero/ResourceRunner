# 개인 사용 성능 개선 명세

## 1. 범위

ROADMAP M5의 첫 범위로 ResourceRunner 자체 CPU·메모리 사용량의 원인을 재현 가능한 조건에서 확인하고,
기존 기능을 유지하면서 상시 실행 비용을 줄입니다. 개인 Mac에 설치한 Release 앱으로 전후 성능을 검증합니다.
이 기능의 완료가 M5 전체의 정확성·접근성·24시간/72시간/7일 장기 검증 완료를 뜻하지는 않습니다.

### 1.1 입력 맥락

- 2026-10-10 사용자 요청: 성능 문제를 줄이는 작업을 진행하기 위한 Phased 착수.
- [ROADMAP](../../ROADMAP.md) 「M5. 개인 사용을 위한 정확성·성능·안정성 검증」과 「최종 관문/성능」,
  [제품 정의](../../docs/product.md) 「메뉴바 캐릭터」·「대시보드」·「설정」·「데이터와 개인정보」,
  [기술 설계](../../docs/design.md) 「성능 설계」·「CPU 상태와 정적 메뉴바 표시」를 기준으로 합니다.
- 기준 branch main, HEAD69842e14e920e95da179f525055b22dd75c56b74와 현재 미커밋 변경을 포함합니다.
  정적 CPU 색상·1pt 포커스·개인 사용 범위 변경은 선행 승인 변경입니다.
  성능 비교용 빌드마다 전체 수정 파일의 해시와 빌드 구성을 기록하여 HEAD만으로 같은 빌드라고 간주하지 않습니다.

## 2. 목표

- 동일 환경의 팝오버 닫힘·본체 열림·상세 열림·설정창만 열림을 구분해 비용 원인을 확인합니다.
- 표시하지 않는 화면의 불필요한 주기 갱신·레이아웃·그리기와 그래픽 자원 보유를 줄입니다.
- 실제 비용이 확인된 수집·집계·캐시·화면 전달 경로를 개선하며 측정값의 의미를 보존합니다.
- 기존 목표 CPU 평균1%/3% 미만, 메모리100MB 미만, 메뉴바 클릭100ms/팝오버 표시200ms 이내를 유지합니다.
- 메모리 주 지표는 앱 외부에서 측정하는 Physical Footprint이며 RSS·그래픽/heap 내역도 별도 기록합니다.
  메모리100MB는100,000,000bytes입니다. 앱의 다른 프로세스 순위에 쓰는 Resident Memory 정의를 바꾸지 않습니다.
- 미달하면 원인과 남은 변경을 보고하고 목표를 임의 완화하거나 측정 지표 변경으로 통과시키지 않습니다.

## 3. 제약

- 대표 CPU·Memory·Network·Disk 값, TOP5·상세10/20/50·시스템 포함 설정, 최근1/5/10분 그래프,
  앱/하위 프로세스 집계·PID 재사용 처리·실패/중지 안내의 의미를 유지합니다.
- 수집 프로필·주기·저전력·잠금·절전 복귀와 데이터 연속성 계약을 유지합니다.
  설정을 느리게 바꾸거나 카드·TOP5를 숨긴 결과를 기본 구성 최적화라고 보고하지 않습니다.
- 고정18pt 정적 고양이의 CPU 색상·툴팁·접근성 이름, 고정 메뉴바 폭,1pt 포커스 표시를 유지합니다.
- 팝오버/설정창을 열 때 최신 캐시가 즉시 표시되고, 기존 단축키·Escape·포커스 복귀·외부 닫기 정책이 동작해야 합니다.
- 진단 때문에 관리자 권한·별도 Helper·로그인 등록 변경·로그아웃·전원/네트워크 강제 전환을 추가하지 않습니다.
- 검증용 수치 기록은 별도 외부 도구로 기간·용량을 제한합니다. 일반 Release 앱에 상시 로그나 장기 리소스 기록을 추가하지 않습니다.
- 기존 작업 트리와 승인된 과거 근거를 보존합니다. 실제 설치 앱은 원인 조사/개선 구현 중 재시작하지 않고,
  개선 Release 검증 후 같은 경로로 교체하며 사용자 설정·로그인 상태를 보존합니다.
- 최적화로 영향받는 선행 동작은 관련 검증을 다시 수행하고 과거 전체 테스트 통과를 현재 코드의 통과로 대신하지 않습니다.

## 4. 제외 범위

- 외부 배포용 서명·공증·Mac App Store·설치 패키지·업데이트 배포.
- 새 애니메이션·캐릭터·새 리소스 기능, 지표 축소/정의 변경, 새 사용자 성능 설정.
- 앱 자체의 상시 파일 로그·텔레메트리·장기 측정 이력·클라우드 전송.
- 실제 VPN·유선LAN·외장디스크·다른 계정 전환 시험(기존 사용자 제외 유지).
- M5 전체의 장기24시간/72시간/7일 완료 판정과 실제 VoiceOver 낭독 등 별도 최종 관문.

## 5. 완료 조건

1. 고정된 Mac·OS·Release 빌드·설정·워밍업·측정 기간에서 창 표시 상태별 원본 baseline과 개선 결과를
   동일 절차로 수집합니다. CPU는 누적 CPU시간 차분으로 계산하고 RSS·Physical Footprint·구간 최대·실행 최고값을 구분합니다.
   샘플링 누락·PID 변경·잠금/절전·창 상태 변경이 있는 구간은 정상 측정으로 합치지 않습니다.
2. 기본 설정에서 본체·상세·설정창이 모두 닫힌 안정 측정 구간의 평균 CPU가1% 미만입니다.
3. 기본 설정에서 본체 열림, CPU/Memory/Network/Disk 각 상세 열림, 설정창만 열림을 각각 측정하고
   각 안정 구간의 평균 CPU가3% 미만입니다. 주기적인 TOP5·수집 갱신을 포함합니다.
4. §5.2/§5.3의 각 안정 구간에서 Physical Footprint가100,000,000bytes 미만입니다.
   실행 초기·창 전환의 peak는 별도 기록하며 RSS나 그래픽 resident로 대체 판정하지 않습니다.
5. 반복 열기·상세 전환·닫기에서 같은 화면 상태로 돌아온 뒤 메모리/그래픽 자원의 지속적인 누적 증가가 없고,
   측정 기간과 반복 횟수·회수/유지되는 자원을 근거로 설명합니다. 이 결과만으로24시간 이상 누수 없음을 주장하지 않습니다.
6. 메뉴바 클릭 처리100ms 이내·팝오버 표시200ms 이내를 같은 시작/종료 정의로 확인하며,
   첫 열림과 재열림 모두 기존 카드·최신 캐시·그래프와 접근성 값이 올바릅니다.
7. 기존 수집·대표 지표·집계·이력/복귀·실패 표시·네 카드/상세·설정 즉시 반영·키보드/포커스·접근성 계약이
   영향 범위의 단위/통합/UI 검증에서 유지됩니다. 숨긴 동안 최신 자료를 유지하고 다시 열 때 재수집을 기다리지 않습니다.
8. 원본 Debug/Release 빌드와 관련 검증을 완료한 개선 Release를 기존 설치 경로에 반영하고,
   실제 설치 URL에서 단일 앱 실행·설정 보존·로그인 상태·메뉴바/팝오버/설정 접근을 확인합니다.
   다음 로그인 재시험 없이 재시험했다고 주장하지 않습니다.
