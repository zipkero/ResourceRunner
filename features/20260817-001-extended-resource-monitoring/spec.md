# Network·Disk 확장 리소스 모니터링 명세

## 1. 범위

이 feature는 Network와 Disk를 수집해 대시보드 팝오버에 두 카드를 추가하고,
네 리소스를 같은 구조와 상호작용으로 다루는 하나의 대시보드로 완성합니다.

현재 속도, 최근 10분 그래프, 카드 상세 정보와 수집 실패 격리를 포함합니다.
M2가 만든 수집 일정·이력 링·생명주기 제어와 카드 표시 구조에 두 수집 축을 얹습니다.

Network와 Disk는 CPU·Memory와 성격이 다릅니다.
둘 다 누적 카운터의 변화량으로 속도를 만들기 때문에, 카운터 기준이 흔들리는 순간을 값으로 만들지 않는 것이
이 feature의 핵심 난점입니다. 인터페이스 전환, 볼륨 연결·해제, 시스템 슬립 복귀가 모두 그 순간에 해당합니다.

저장 공간은 실시간 I/O와 갱신 성격이 달라 같은 카드 안에서도 책임과 주기를 나눠 다룹니다.

### 입력 맥락

- [docs/product.md](../../docs/product.md)의 `Network`, `Disk`: 기본 카드와 상세 정보에 표시할 항목, 1.0 제외 항목.
- [docs/product.md](../../docs/product.md)의 `대시보드 > 공통 정보 구조`, `대시보드 > 접근성`,
  `최근 그래프와 데이터 보관`: 네 카드가 공유하는 표시 원칙, 접근성 요구와 그래프 보관 정책.
- [docs/design.md](../../docs/design.md)의 `Network`, `Disk`: 수집 대상과 기준점 재설정 요구.
- [docs/design.md](../../docs/design.md)의 `수집 일정 > 기본 정책`: Network RX·TX와 전체 Disk I/O는 열림 1초·닫힘 2초,
  디스크 여유 공간은 30초·60초, 인터페이스 주소·상태는 변경 감지 또는 30초·60초.
- [docs/design.md](../../docs/design.md)의 `실패와 데이터 상태`: Collector 하나의 실패가 다른 Collector와 전체 UI를 막지 않습니다.
- [features/20260812-001-core-resource-monitoring/spec.md](../20260812-001-core-resource-monitoring/spec.md)의 `제외 범위`:
  "시스템 슬립 복귀 후 첫 샘플의 기준점 재설정"을 "변화량으로 속도를 계산하는 지표가 없는 동안에는 필요하지 않습니다"라는
  사유로 미뤘습니다. Network와 Disk가 그 지표라 이 feature에서 다룹니다.

기존 표시 구조를 확인한 결과, 카드가 넷으로 늘어나는 것 자체는 더하기로 끝납니다 —
카드 표시 상태 타입이 이미 제네릭이고 선택 상태도 카드를 인자로 받습니다.

이 feature를 시작하며 `docs/product.md`의 상세 표시 방식이 「하단 고정 영역」에서 「카드 옆 팝업」으로 바뀌었고,
레이아웃 안정성 원칙이 값 변화뿐 아니라 상태 전이까지 덮도록 확장됐습니다.
두 변경은 이미 완성된 CPU·Memory 카드에도 적용되므로 core-resource-monitoring SPEC이 함께 갱신됩니다.
상세가 본체 밖으로 빠지면서 팝오버가 상세 자리를 예약할 필요가 없어져 카드 넷을 세로로 담을 여유가 생깁니다.

카드 옆 팝업이 실제로 성립하는지는 실행 환경에서 먼저 확인했습니다.
메뉴바 팝오버는 `.transient`라 자식 팝업이 부모를 닫을 수 있다는 우려가 있었으나,
카드 클릭은 부모 창 안에서 일어나므로 닫힘 계기가 아니며 두 팝오버가 공존했습니다.
자식 팝업이 접근성 계층에서 부모 팝오버의 하위 노드로 들어가 내용도 그대로 도달됐습니다.

이 SPEC 작성 전에 확정한 판단은 다음 둘입니다.

- 대표 속도는 물리 인터페이스 합계로 하고 VPN 터널 인터페이스는 상세에만 둡니다.
  VPN 트래픽이 터널과 물리 인터페이스를 모두 지나 단순 합산하면 이중 계산되기 때문입니다.
  검토했으나 접은 것은 둘입니다 — 활성 기본 경로 인터페이스 하나만 대표로 쓰는 방식은
  동시에 쓰는 다른 인터페이스의 트래픽이 대표값에서 빠지고,
  loopback 제외 전체 단순 합산은 VPN 사용 중 속도가 약 2배로 부풀려 보입니다.
- 프로세스별 Disk I/O는 이 feature에서 다루지 않습니다.

## 2. 목표

사용자가 CPU·Memory에 더해 네트워크와 디스크까지 한 팝오버에서 확인하고,
네 리소스 중 어디에서 문제가 일어나는지 같은 방식으로 읽어 낼 수 있게 합니다.

지금은 네트워크가 느리거나 디스크가 바쁜 상황을 앱이 전혀 설명하지 못합니다.
사용자는 그 순간 Activity Monitor나 다른 도구로 옮겨 가야 하며, 메뉴바 상주 앱의 값이 그만큼 줄어듭니다.

동시에 네 카드가 서로 다른 규칙으로 자라지 않게 막습니다.
카드마다 상태 표현과 단위 표기가 달라지면 사용자는 카드마다 읽는 법을 새로 배워야 합니다.

## 3. 제약

- App Sandbox를 유지합니다. 별도 Helper, 관리자 권한과 사용자 승인 프롬프트를 요구하지 않습니다.
- 수집 데이터는 외부로 전송하지 않고 앱 메모리에만 유지하며, 앱 재시작 후 복원하지 않습니다.
- 그래프 시간 범위는 최근 10분 하나이며 사용자에게 범위 선택을 노출하지 않습니다.
  1분·5분·10분 선택은 ROADMAP §M4의 사용자 설정에 속합니다.
- 존재하지 않는 과거 데이터를 만들지 않습니다. 수집하지 않은 구간은 그래프에서 비워 둡니다.
- 일시적 수집 실패를 0으로 표시하지 않습니다.
- 수집 주기는 M2가 만든 일정 제어를 따릅니다.
  팝오버가 닫히면 감속하고 화면을 볼 수 없는 상태에서는 중지합니다.
- 저장 공간 조회는 실시간 I/O보다 느린 주기로 돌며, 두 갱신 주기가 한 카드 안에서 섞이지 않습니다.
- 카드 상세는 그 카드 옆에 붙는 팝업으로 열립니다.
  대시보드 본체는 상세를 위한 자리를 예약하지 않으며, 상세를 열고 닫아도 카드가 움직이지 않습니다.
- 카드 높이는 수집 상태와 무관하게 일정합니다.
  아직 값이 없는 그래프와 순위 자리는 같은 높이의 자리표시로 채웁니다.
- 색상만으로 정상·경고·위험을 구분하지 않습니다.
- 카드의 현재 상태와 주요 수치에 접근성 이름을 제공하고, 핵심 흐름을 키보드로 탐색할 수 있어야 합니다.
- 이미 완성된 CPU·Memory 카드의 확정된 동작을 약화시키지 않습니다.
- 앱 자체의 수집 활동이 Network·Disk 측정 결과를 의미 있게 왜곡하지 않아야 합니다.

## 4. 제외 범위

- 프로세스별 네트워크 사용량, 원격 호스트, 포트별 통계, 패킷 캡처와 Network Extension.
- 프로세스별 Disk I/O와 앱 단위 Disk 순위.
  ROADMAP §M3의 완성 결과와 전환 기준에 없고 `docs/product.md`도 후보로만 적어 둔 항목이라
  1.0 이후로 미룹니다.
- 캐릭터의 Disk 발밑 효과와 Network 이동 효과.
  캐릭터 자산 제작과 메뉴바 애니메이션 전체가 별도 feature에 속합니다.
- 그래프 시간 범위 선택(1분·5분·10분)과 사용자 갱신 속도 설정.
- 설정의 영구 저장, 기본값 복원과 로그인 시 자동 실행.
- 네트워크 속도 임계치에 따른 경고나 알림.
- VoiceOver 실제 낭독 확인, 성능·장기 안정성 관문과 정확성 최종 검증.
- 코드 서명, 공증, 업데이트 전달과 설치 가능한 배포물.

## 5. 완료 조건

1. 팝오버를 열면 Network 카드에 현재 다운로드 속도, 현재 업로드 속도, 최근 10분 송수신 그래프,
   현재 활성 인터페이스와 Wi-Fi·Ethernet·VPN 구분이 표시됩니다.
2. 팝오버를 열면 Disk 카드에 현재 읽기 속도, 현재 쓰기 속도, 최근 10분 입출력 그래프,
   시스템 볼륨 전체 용량과 사용 가능한 공간이 표시됩니다.
3. Network 카드를 선택하면 그 카드 옆에 열리는 팝업에 인터페이스별 RX와 TX, IPv4와 IPv6 주소,
   누적 송수신량, 인터페이스 상태, 복수 인터페이스 사용 상태가 표시되고,
   다시 선택하면 팝업이 닫히며 요약 상태로 돌아옵니다.
4. Disk 카드를 선택하면 그 카드 옆에 열리는 팝업에 볼륨별 전체·사용 중·사용 가능한 공간,
   장치별 읽기·쓰기 속도, 누적 읽기·쓰기 크기, 외장 디스크 상태가 표시되고,
   다시 선택하면 팝업이 닫히며 요약 상태로 돌아옵니다.
5. 카드의 대표 속도가 물리 인터페이스 합계이고 VPN 터널 인터페이스는 대표값에 더해지지 않습니다.
   VPN을 연결하고 해제해도 같은 트래픽에서 대표 속도가 약 2배로 뛰지 않으며,
   터널 인터페이스는 상세 정보에서 확인됩니다.
6. 대용량 다운로드·업로드에서 Network 값이, 대형 파일 읽기·쓰기에서 Disk I/O 값이 기대한 방향으로 변하고,
   정해진 비교 절차에서 macOS 시스템 도구와 변화 방향이 일치합니다.
7. Wi-Fi와 Ethernet 전환, VPN 연결과 해제, 네트워크 연결 없음, 외장 디스크 연결과 해제에서
   음수나 비정상적인 급증 같은 순간값이 나타나지 않고 앱이 종료되지 않습니다.
8. 시스템 슬립에서 복귀한 첫 샘플이 수면 시간을 경과 시간으로 삼은 속도를 만들지 않고 기준점만 갱신하며,
   중지된 구간이 그래프에서 비어 있습니다.
9. 인터페이스 집합이나 누적 카운터의 기준이 바뀌면 그 다음 첫 샘플을 새 기준점으로 처리해
   이전 값과 이어 붙이지 않습니다.
10. 저장 공간이 실시간 I/O보다 느린 주기로 갱신되고, 두 갱신 주기의 차이가
    카드에서 값이 멈춘 것처럼 보이는 오해를 만들지 않습니다.
11. Network 또는 Disk 수집이 실패해도 그 카드만 실패 상태가 되고,
    나머지 세 카드와 메뉴바 앱은 계속 동작합니다. 반대 방향도 같습니다.
12. 네 카드가 같은 구조와 상호작용을 공유합니다 — 요약과 선택·복귀 방식,
    수집 중·정상·실패·중지 상태 표현, 속도와 크기의 단위 표기가 카드마다 다르지 않습니다.
13. 선택한 배포·Sandbox 조건에서 1.0에 필요한 Network·Disk 지표의 접근 가능 범위가 검증되고,
    얻을 수 없는 항목은 근거와 함께 기록됩니다.
14. 두 카드의 현재 상태와 주요 수치에 접근성 이름이 제공되고 키보드로 탐색할 수 있으며,
    색상 없이도 상태를 구분할 수 있습니다.
    상세 팝업의 내용도 접근성 계층에서 도달할 수 있습니다.
15. 팝오버를 연 직후 아직 값이 없는 상태에서 첫 수집이 도착해도 카드의 크기와 위치가 변하지 않습니다.
    수집 중·정상·실패·중지 사이를 오갈 때도 같으며, 값이 없는 그래프와 순위 자리는
    비워 두지 않고 같은 높이의 자리표시로 채웁니다.
    상세 팝업을 열고 닫아도 카드가 움직이지 않습니다.
