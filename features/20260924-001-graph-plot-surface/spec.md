# 그래프 판의 영역 표시

## 1. 범위

CPU 카드 그래프 판이 **어디서 시작해 어디서 끝나는지**를 화면에서 드러냅니다.
판 영역 전체에 옅은 면을 깔아 0%·100%와 시간 창 양끝이 면의 가장자리로 읽히게 하는 작업입니다.
가로 기준선은 50% 하나를 그대로 두고, 선을 새로 더하지 않습니다.

표시하는 값·계열·기준선 값·시간 창·크기는 바꾸지 않습니다.

### 입력 맥락

`20260903-001-dashboard-visual-refinement`의 `task-008` 실기기 확인 중에 사용자가 팝오버 캡처를 보고
「그래프의 위 아래 영역의 구분이 없어서 뭔가 이상함」이라고 지적한 것이 출발점입니다.

캡처에서 확인한 상태:

- 앱 실행 43초 시점이라 데이터가 10분 창의 오른쪽 끝 좁은 폭에만 있고, 전체 CPU 7%라 밴드 높이도 몇 pt에 그칩니다.
- 판에서 보이는 것이 50% 기준선 하나뿐이라 그 선이 판을 위아래로 가르는 경계처럼 읽히고,
  선 위쪽 절반은 판이 아니라 카드 안의 빈 여백처럼 보입니다.

같은 불편이 두 번째로 나온 것입니다.

- `20260906-001-graph-legibility-and-color`가 「그래프가 영역이 잘 느껴지지 않는다」는 지적을 받았습니다.
  그때 원인을 「0%·100% 경계선이 없고, 카드 채움이 없어 그래프 뒤에 남은 면도 없다」로 짚고 판 둘레에 닫힌 사각 테두리를 넣었습니다(그 feature의 spec.md §1, design.md 「판 경계」 결정).
- `20260912-001-dashboard-visual-language`가 그 테두리를 지웠습니다(design.md DP5 옵션 C).
  0%·100% 경계는 판 높이 자체와 판 바로 아래 축 라벨 줄이 나타낸다고 보았고, 위끝이 선으로 표시되지 않는 대가를 알고 받아들였습니다.
  같은 feature의 design.md DP6 옵션 A가 이번 방향(판 전체에 카드 면보다 한 단 낮은 면)이었고,
  「면 단계가 바탕·카드에 이어 셋이 된다」와 「보조 표시가 데이터보다 강한 상태를 면으로 되살린다」를 이유로 접었습니다.
- 이번 캡처는 「판 높이와 축 라벨 줄이 경계를 나타낸다」는 판단이 수집 초기처럼 판이 거의 빈 화면에서 성립하지 않는다는 새 근거입니다.

`/spec-init` 전에 사용자와 정한 방향과 접은 접근:

- 채택 — 판 영역에 옅은 면을 깔고, 선은 50% 기준선 하나를 유지합니다.
- 접음: 0% 바닥선만 추가 — 「가로 기준선 하나만」을 고쳐야 하고 천장은 여전히 표시되지 않습니다.
- 접음: `20260906`의 닫힌 테두리 복원 — `20260912`가 없애려 한 「보조 표시가 데이터보다 강한 상태」가 돌아옵니다.
- 접음: 유지 — 이번 지적이 해소되지 않습니다.

조사 출처:

- `docs/product.md` §대시보드 §공통 정보 구조 — 「그래프 판에는 값의 높이를 어림하는 가로 기준선 하나만 두고 세로 눈금과 판 테두리를 두지 않습니다」, 자리표시와 레이아웃 안정성 원칙
- `docs/product.md` §CPU §기본 카드 — User와 System이 그래프 안에서 구분되고 기준선을 함께 둔다
- `docs/product.md` §대시보드 §접근성 — 동작 줄이기와 애니메이션 비활성화에서도 같은 정보
- `docs/design.md` — 카드 넷을 가정한 세로 예산에서 그래프 판 100pt가 기준 기기의 상한
- `ROADMAP.md` §현재 상태 M2 행, M3 전환 기준 「네 카드의 구조, 단위와 상호작용이 일관됩니다」
- `features/20260912-001-dashboard-visual-language/spec.md` §3 — 카드는 라이트·다크 모두에서 바탕 위로 떠오르고, 새 색은 실제로 놓이는 면을 기준으로 대비를 잰다

## 2. 목표

그래프를 처음 보는 순간 판의 범위가 읽히게 합니다.
데이터가 몇 pt뿐이거나 창의 일부만 차 있어도, 어디가 0%이고 어디가 100%인지, 어디가 시간 창의 양끝인지가 판의 모양만으로 드러나야 합니다.
50% 기준선이 판을 가르는 경계가 아니라 판 안의 눈금으로 읽혀야 합니다.

그러면서도 `20260912-001`이 세운 방향 — 보조 표시가 데이터보다 먼저 눈에 들어오지 않고, 판이 여러 칸으로 갈라져 보이지 않는 것 — 은 되돌리지 않습니다.
판의 범위를 선이 아니라 면으로 알리는 이유가 이것입니다.

M3에서 Network·Disk 그래프가 더해질 때 같은 판 규칙을 그대로 쓸 수 있게, 이 규칙을 CPU 전용이 아니라 대시보드 그래프 판의 규칙으로 정합니다.

## 3. 제약

판 위의 선은 50% 가로 기준선 하나뿐입니다.
세로 눈금·판 테두리·0%·100% 선을 더하지 않고, 면의 가장자리에 윤곽선을 긋지 않습니다.

판 면은 데이터보다 약해야 합니다.
User·System 두 밴드와 기준선이 판 면 위에서 지금 카드 면 위에서만큼 읽혀야 하며, 판 면이 밴드보다 먼저 눈에 들어오지 않습니다.
두 밴드 색은 라이트·다크 각각에서 새 판 면을 배경으로 기존 대비 기준(3:1 이상)을 지켜야 합니다 — 대비를 재는 배경은 카드 면이 아니라 밴드가 실제로 놓이는 판 면입니다.
기준선은 시스템 구분선 색이라 이 대비 기준의 대상이 아니며, 판 면 위에서 변경 전 카드 면 위에서만큼 보이면 됩니다.

판 면은 라이트·다크 각각에서 카드 면과 구분되어야 하고, 카드가 바탕 위로 떠오르는 기존 관계를 흐리지 않아야 합니다.
라이트와 다크 값은 각각 따로 확정하며, 한쪽 값에서 반전으로 유도하지 않습니다.

판 면은 시간 창 전체를 덮습니다.
수집된 구간에만 깔리거나 수집되지 않은 구간만 따로 칠해지지 않아, 아직 수집되지 않은 구간이 자기 경계를 가진 면으로 보이지 않는다는 기존 조건(`20260912-001` 완료 조건 3)이 그대로 성립합니다.

값이 없는 자리표시도 같은 판 면을 같은 크기·같은 자리에 그립니다.
값 있음과 값 없음 두 경로의 판 모양이 갈리지 않습니다.

그래프 판의 크기·위치와 카드·팝오버의 고정 크기는 바꾸지 않습니다.
판 높이 100pt가 카드 넷 세로 예산의 상한이라는 `docs/design.md`의 계산이 그대로 성립해야 합니다.

애니메이션을 도입하지 않습니다.
갱신 주기마다 하는 일이 늘지 않습니다 — 새 타이머·새 관찰자·새 이미지 생성·색 보간을 두지 않습니다.

접근성으로 도달하는 정보는 줄지 않습니다.
판 면은 값이 아닌 장식이라 접근성 계층에 새 요소나 새 문구를 더하지 않습니다.

## 4. 제외 범위

User·System 두 밴드의 색·채움 밀도·경계선 모양은 대상이 아닙니다.

50% 기준선의 값·색·두께는 대상이 아닙니다.

그래프 판의 높이·폭, 시간 창 10분, 다운샘플 규칙, 축 라벨 줄의 문구는 바꾸지 않습니다.

그래프 시간 범위 선택(1분·5분·10분)은 대상이 아닙니다.

Network·Disk 그래프의 구현은 M3가 소유합니다. 이 feature는 그들이 따를 판 규칙을 정할 뿐입니다.

상세 팝업, Memory 카드, 코어 격자는 대상이 아닙니다.

## 5. 완료 조건

1. 라이트·다크 모두에서 CPU 카드 그래프 판의 범위가 면으로 보입니다.
   판의 위끝이 100%, 아래끝이 0%, 좌우 끝이 시간 창의 양끝이라는 것이 면의 가장자리로 읽히며,
   데이터가 창의 일부에만 있거나 밴드 높이가 몇 pt뿐인 화면(수집 초기, 낮은 부하)에서도 같습니다.

2. 50% 기준선이 판을 위아래로 가르는 경계가 아니라 판 안의 눈금으로 읽힙니다.
   기준선 위쪽 절반이 카드 안의 빈 여백이 아니라 판의 일부로 보입니다.

3. 판 위의 선은 50% 가로 기준선 하나뿐입니다.
   세로 눈금·판 테두리·0%·100% 선이 없고, 판 면의 가장자리에 윤곽선이 없습니다.

4. 판 면이 데이터보다 약합니다.
   User·System 두 밴드 색이 라이트·다크 각각에서 판 면을 배경으로 3:1 이상의 대비를 가지고,
   기준선은 판 면 위에서 변경 전 카드 면 위에서만큼 보이며,
   두 밴드의 구분은 변경 전 카드 면 위에서와 같은 수단으로 계속 됩니다.

5. 판 면이 라이트·다크 각각에서 카드 면과 구분되고, 카드가 바탕보다 떠올라 보이는 관계는 변경 전과 같습니다.

6. 아직 수집되지 않은 구간이 자기 경계를 가진 면으로 보이지 않습니다.
   판 면은 수집 여부와 관계없이 시간 창 전체를 같은 모양으로 덮고, 창이 다 찬 뒤와 수집 초기의 판 모양이 같습니다.

7. 값이 없는 자리표시와 값이 있는 그래프가 같은 크기·같은 자리의 같은 판 면을 보입니다.
   수집 중·정상·실패·중지 사이를 오가도 판과 카드·팝오버의 크기·위치가 변하지 않습니다.

8. 접근성으로 도달하는 정보가 변경 전과 비교해 하나도 줄지 않고, 판 면 때문에 새로 낭독되는 요소도 없습니다.

9. 동작 줄이기와 애니메이션 끄기에서 표시가 달라지지 않고,
   팝오버를 열어 둔 채 관찰한 앱 자신의 CPU 사용량이 변경 전과 비교해 지속적으로 상승하지 않습니다.

10. `docs/product.md`의 그래프 판 규칙이 현재 화면과 어긋나지 않습니다.
    판이 면으로 범위를 나타낸다는 것이 대시보드 그래프 판 공통 규칙으로 적혀 있어, M3의 Network·Disk 그래프가 같은 규칙을 참조할 수 있습니다.
