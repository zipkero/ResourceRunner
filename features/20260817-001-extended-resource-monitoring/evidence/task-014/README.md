## 기존 환경·보류 이력

실제 전환 성공 근거가 아닌 현재 환경 입력입니다. `environment-input.txt`에는 macOS 정보, 등록된 VPN 서비스, 하드웨어 포트, 현재 네트워크 상태와 외장 디스크 목록의 읽기 전용 조회 결과를 보존했습니다.

- 등록된 VPN 서비스와 연결된 외장 디스크가 없습니다. 사용자가 장비 문의에 “그럼 그건 패스해”라고 답해 실제 VPN·외장 연결/해제 관찰을 보류했습니다.
- 현재 활성 네트워크 경로는 Wi-Fi en0이며 실제 Ethernet 링크 전환 장비를 확보하지 못했습니다. Wi-Fi↔Ethernet·연결 없음/복귀 시나리오도 이번에 실행하지 않았습니다.
- task014는 미완료입니다. 결정적 mock·일반 수집·시스템 도구 부하 비교가 실제 장비 전환의 baseline/수명 관문을 대신하지 않습니다. 재개 시 실제 장비·서비스를 확보해 전후 원시값·표시·baseline을 확인해야 합니다.
- 잠금·절전 및 화면 수면·사용자 전환(task015)도 사용자 지시로 보류합니다. 이 파일은 해당 시스템 전이를 실행한 근거가 아닙니다.
