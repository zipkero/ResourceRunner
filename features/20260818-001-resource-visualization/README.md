# resource-visualization

## 요약

이미 동작하는 CPU·Memory 카드와 상세 팝업이 값을 보여주는 방식을 바꿉니다.
상세 순위 정원 확장과 CPU 상세 앱 순위 섹션, Memory 구성 항목 시각화,
CPU 그래프의 격자와 User·System 2계열, 목록의 앱 아이콘을 다룹니다.

  Memory 카드 높이를 늘리는 방향도 접고 기존 텍스트 줄을 그래프가 대체하도록 했습니다 —
  본체 팝오버 높이가 두 카드 기준 실측값이고 M3에서 카드가 넷으로 늘어나기 때문입니다.
  승인 전 확인 한 건이 남아 있습니다 — 누적 바 색 구간 합과 「사용 중」 수치의 관계.
  둘이 같은 정의가 아니라(task-001에서 Activity Monitor 공식으로 확정) 화면에서 어긋나 보일 수 있습니다.
- 2026-08-18: SPEC 재작성. 승인 전 확인 한 건에 답을 받아 반영했습니다 —
  누적 바 구간 합과 「사용 중」 수치를 별개 지표로 분리합니다.
  구간 합을 「사용 중」에 맞추는 두 방식은 접었습니다 —
  「사용 중」 정의를 되돌리면 Activity Monitor 편차 0 일치가 깨지고(task-001 결정),
  「사용 중」을 바의 채운 길이로 삼으면 구간 길이가 실제 바이트에 비례하지 않아 값이 왜곡됩니다.
  §3에 값 왜곡 금지와 두 지표 구분을, §4에 「사용 중」 정의 변경 제외를, §5.3에 비례·구분 요구를 더했습니다.
- 2026-08-18: ANALYSIS 작성.
  표시 계층 안에서 끝나는 변경을 원칙으로 하고 예외 하나를 확정했습니다 —
  CPU 그래프 2계열은 시각별 User 값을 요구하므로 이력 항목에 필드 하나가 늘어납니다.
  Memory 구성 시각화는 최신 스냅샷만 쓰므로 이력 계약을 요구하지 않습니다.
  상세 순위와 전체 프로세스 목록을 목록 하나로 통합했습니다 —
  같은 순위가 두 번 나타나지 않는 것을 표시 값 모델에서 순위 필드를 하나만 남겨 보장하고,
  정원은 순서 고정과 같은 순수 함수 안에서 걸어 펼친 행이 있는 동안 목록 구성이 흔들리지 않게 했습니다.
  Memory 상세에 이미 있던 「현재 사용량 순위」와 전체 목록의 중복도 이 통합으로 함께 해소됩니다.
  Memory 카드는 Pressure·Swap 줄을 합쳐 구성 범례 자리를 만들고 잘림 우선순위를 서식 순서로 고정했습니다.
  Decision Point 16개를 확정했고 남은 미해결 결정은 없습니다.
  통합의 대가를 §4에 기록했습니다 — 상세 목록이 전체에서 정원까지로 줄어 정원 밖 앱은 상세에 나타나지 않습니다.
