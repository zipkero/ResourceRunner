# 대시보드 그래프 가독성과 색감 회복

## 요약

CPU 그래프를 키우고 시간 축을 두어 최근 흐름을 눈으로 따라갈 수 있게 하고, 리소스당 고유 색조로 되돌려 화면에서 리소스를 색으로 구분하게 합니다.
코어 격자의 색, 상세 하위 행의 세로 간격, 카드 순위 안내 문구도 함께 다시 정합니다.
